### Реализовано

- `backend/include/webwb/project_validation.hpp` и `backend/src/project_validation.cpp` — отдельный C++17 валидатор JSON проекта версии 3 через системную библиотеку `json-c`.
- `backend/src/main.cpp` — новый тестовый маршрут `POST /api/projects/validate` (200 для корректного, 400 для некорректного). `GET /api/health` сохранён.
- `CMakeLists.txt` — обнаружение `libjson-c-dev`, сборка общего модуля валидации и отдельного теста.
- `backend/tests/project_validation_test.cpp`, `tests/fixtures/project-v3.json` — набор тестов и настоящий пример из `frontend/js/model.js`.
- `docs/PROJECT_FORMAT.md`, `docs/ARCHITECTURE.md`, `docs/ROADMAP.md`, `README.md`, `backend/README.md` — документирован формат и этап.

### Правила формата

- `version` строго `3`, корень — `container`; пять типов элементов, уникальные ID, разрешённые свойства оформления.
- Не более 400 узлов, глубина до 20 ниже корня, объём JSON до 1 МиБ; проверка формата чисел, булевых полей и вложенности.
- Старые версии 1/2 сначала импортируются в редактор, затем экспортируются как версия 3.
- Для нового endpoint нет создания проекта, чтения файлов и серверного хранилища. Это только диагностическая проверка.
