## Текущий шаг — 11: MQTT только на чтение

**Статус:** исходники подготовлены, архив ожидает тестов владельца и нового коммита. Шаг 12 не начат.

Изменения:
- `frontend/js/mqtt_reader.js` — маленький клиент MQTT 3.1.1 over WebSocket (CONNECT/SUBSCRIBE/PINGREQ; сообщения PUBLISH только принимаются), QoS 0, повторное подключение, состояние связи.
- `frontend/viewer.js`, `frontend/viewer.html`, `frontend/js/renderer.js` — подписка и отображение сообщений в отдельном просмотре. Связанные с MQTT кнопки/переключатели/ползунки **не отправляют команды**.
- `frontend/js/properties.js` — свойство MQTT `statusTopic` и `activeValue` у кнопки/переключателя, подсказки «i»; MQTT в редакторе не подключается.
- `frontend/js/model.js`, `backend/src/project_validation.cpp` — сохраняются и проверяются необязательные статусные поля в JSON версии 3, прошлые проекты совместимы.
- `backend/tests/project_validation_test.cpp` — тест допустимых/недопустимых MQTT-привязок.
- `tests/mqtt_reader_test.js`, `tests/check.sh` — тест клиентской подписки без брокера, одной командой с остальными тестами (Node.js необязателен: без него тест MQTT-клиента пропускается).
- `README.md`, `docs/{ROADMAP,STATE,ARCHITECTURE,PROJECT_FORMAT,VIEWER}.md` — актуализированы.

## Проверить владельцу

1. Распаковать ZIP в `C:\Projects\WEBWB`.
2. WSL: `bash tests/check.sh` (одна команда).
3. При необходимости запустить `bash tests/run_editor.sh`, в браузере Windows открыть вручную `http://localhost:8090/`, выбрать элемент и назначить его MQTT-топик. Без MQTT-прокси dev-сервер покажет «нет соединения», что нормально для данного шага.
4. Commit/push и прислать SHA, либо прислать ошибку.

## Ограничения и последующие шаги

- **Следующий шаг 12 — публикация MQTT-команд**. На шаге 11 никаких исходящих `PUBLISH` нет, backend не подключается к брокеру.
- Шаги 13–15: кросс-сборка под WB, nginx/systemd, проверка настоящего MQTT на контроллере.
- По просьбе владельца **отложена** замена отдельного элемента изображения картинкой в фоне обычного контейнера. На шаге 11 эта функция не меняется.
- Frontend HTML/CSS/Vanilla JS, backend C++17, файлы JSON и uploads, без собственной авторизации и без SCADA-функций.
- Команды Git: `git add .`, без `git diff --check`. Доставка только архивом. Приложение рассчитано на доверенную локальную сеть.
