## Проверка владельцем

1. Распаковать ZIP поверх `C:\Projects\WEBWB`.
2. В WSL: `bash tests/check.sh`.
3. В WSL: `bash tests/run_editor.sh`; открыть http://localhost:8090/ в браузере Windows.
4. Выбрать контейнер со вложенными элементами, «Сохранить как шаблон», перетащить шаблон на холст. Обновить страницу: шаблон остаётся. Удалить и обновить: исчез. Если шаблоны ранее были сохранены в `localStorage` адреса `http://localhost:8090/`, они должны перенестись на backend при первом подключении. Шаблоны, созданные под `file://`, автоматически могут быть недоступны из-за изоляции хранилища браузером.
5. Commit/push владельцем, сообщить SHA; при ошибках прислать вывод.

## Ограничения

- Проекты и шаблоны хранятся в отдельных JSON-файлах на сервере, сервер без собственной авторизации; только контролируемая локальная сеть.
- Сохранение новых шаблонов без HTTP/backend не поддерживается; для работы использовать dev-сервер (не `file://`). Старые локальные шаблоны остаются доступными как резервный источник до успешной миграции.
- На одном сервере до 30 шаблонов; при достижении лимита — HTTP 409.
- MQTT, загрузка изображений, общие настройки, nginx/systemd, кросс-сборка для WB пока отсутствуют.
- Git только у владельца: `git add .`, без `git diff --check`.
