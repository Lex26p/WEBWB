**02c — полное скругление больших квадратов**, frontend v0.3.4.
Статус: **архив подготовлен, ожидает проверки и коммита владельца**. Шаг 03 не начат.

### Изменения

- `frontend/app.js`: у настройки скругления появился флажок «Полное скругление». В обычном режиме — ползунок `0–50px`; в полном режиме — CSS `border-radius: 9999px`. У квадрата любого размера при этом круглые края, у прямоугольника — капсула с круглыми концами. Нет вычислений размеров и `%` для полного режима.
- Нормализация проекта и шаблонов сохраняет значение `9999px` без обрезания до `50px`. Старые проекты по-прежнему открываются; прежние значения в процентах по существующим правилам приводятся к пикселям.
- Отключение полного режима устанавливает `50px`, затем ползунок можно передвинуть на любое значение от 0 до 50.
- `frontend/index.html`: версия v0.3.4.
- `README.md`, `docs/PROTOTYPE_V03.md`, `docs/ROADMAP.md`, `docs/STATE.md`: документация обновлена.

### Проверки у владельца

1. Создать контейнер размером `300px` × `300px`, задать фон, поставить флажок «Полное скругление»: контейнер становится кругом.
2. Изменить размер на `500px` × `500px`: элемент остаётся круглым.
3. Сделать размер `300px` × `100px`: получаем капсулу без эллиптических углов.
4. Выключить «Полное скругление»: появляется обычное значение `50px` и становится доступен ползунок.
5. Сохранить и снова загрузить проект; проверить сохранение полного режима. Аналогично проверить сохранённый шаблон.
6. Проверить базовые операции Drag & Drop и режим просмотра.
7. Commit/push и новый хеш присылает владелец.

## Правила

- Git: `git add .`, **без** `git diff --check`.
- Frontend: HTML/CSS/Vanilla JS; backend: C++/CMake; хранение: JSON, без СУБД; MQTT только в просмотре; собственной авторизации нет.
- Один шаг за цикл, исходные файлы передаются только в ZIP; GitHub изменяет только владелец.
