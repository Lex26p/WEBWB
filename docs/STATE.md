## Проверка владельцем

1. Распаковать `WEBWB-step-09.zip` поверх рабочей копии.
2. В WSL выполнить `bash tests/check.sh`.
3. В WSL выполнить `bash tests/run_editor.sh`, открыть вручную `http://localhost:8090/`.
4. Перетащить «Изображение», выбрать его, загрузить PNG/JPEG/WebP, затем сохранить проект. Обновить страницу и открыть проект с сервера: изображение должно сохраниться и отображаться.
5. Если всё успешно — commit/push и прислать SHA; при ошибке — полный вывод проверки и описание поведения.

## Ограничения и принципы

- Фото и рисунки хранятся отдельно от JSON проектов. Экспорт проекта JSON не экспортирует байты изображения.
- Отдельный UI настроек пока не вводился; `GET/PUT /api/settings` доступен API-клиенту.
- Настройки `title` ограничены строкой до 120 байт. Не сохраняем пароли и MQTT-настройки на этом этапе.
- Загружаются только PNG, JPEG и WebP размером до 1 МиБ; удаление изображения не исправляет ссылки внутри существующих проектов.
- MQTT, nginx/systemd, WB-кросс-компиляция — следующие этапы. Нет React, базы данных или собственной авторизации.
- Git: `git add .`, без `git diff --check`. Исходники выдаются архивом; GitHub изменяет только владелец.
