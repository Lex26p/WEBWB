## Что проверить владельцу

1. Распаковать ZIP поверх рабочей копии; выполнить `bash tests/check.sh` в WSL.
2. Запустить `bash tests/run_editor.sh` и открыть вручную `http://localhost:8090/`.
3. Открыть или создать проект, сохранить его; нажать «Открыть панель» — откроется отдельная страница **без редактора**.
4. Сделать изменение без сохранения: отдельная страница всё ещё показывает сохранённую версию. Сохранить и обновить вкладку viewer: изменение появится.
5. При отсутствии `id`/неверном ID viewer выводит ошибку.
6. Если всё успешно — commit/push и SHA; если нет — текст ошибки и вывод теста.

## Зафиксированные решения

- Frontend HTML/CSS/Vanilla JS, backend C++17/Boost.Beast/json-c; JSON/файлы на контроллере, без SQL и собственной авторизации.
- MQTT только в режиме просмотра; реальные статусы и отправка команд — шаги 11–12; автоматика остаётся в Wiren Board.
- **Изображения:** владелец предпочитает фон контейнера вместо самостоятельного компонента, но на шаге 10 ничего не меняем.
- Git делает владелец; команды только `git add .`, без `git diff --check`; один шаг за цикл.
