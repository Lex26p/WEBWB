## Проверить владельцу

1. Распаковать ZIP поверх `C:\Projects\WEBWB`.
2. WSL: `bash tests/check.sh` (одна команда). Для MQTT-тестов нужен Node.js.
3. В WSL: `bash tests/run_editor.sh`, открыть вручную `http://localhost:8090/`, выбрать кнопку, переключатель и ползунок: в свойствах должны быть новые настройки «MQTT · действие». Сохранить проект. В режиме просмотра без брокера появится сообщение об отсутствии MQTT-соединения — это ожидаемо.
4. После успеха прислать хеш коммита. При ошибке — вывод терминала.
