## Подтверждённые решения

- В Git-командах использовать `git add .`, не включать `git diff --check`.
- Скругление — стандартный CSS `border-radius` в процентах; без вычисления радиуса на основе ширины или высоты.
- Бэкенд C++, frontend Vanilla JS, storage JSON, MQTT только для просмотра, собственная авторизация не нужна.

## Проверка шага 02a

1. Открыть `frontend/index.html`; у элемента в «Граница» указано значение `%`, без переключения подписи на `px` при изменении ползунка.
2. При движении ползунка проверить отображение `0%`, `25%`, `50%` и изменение формы элемента.
3. Открыть старый JSON с `borderRadius` в `px`: прежнее скругление сохраняется до ручного изменения; после движения ползунка сохраняется значение в `%`.
4. Проверить сохранение JSON, повторное открытие и отсутствие регрессий в Drag & Drop.
5. При успешной проверке владелец делает commit/push и присылает новый hash.
