## Текущий шаг

**02b — исправление формы скругления**, версия frontend v0.3.3. **Архив подготовлен**, ожидаются распаковка, ручная проверка и коммит владельца. Шаг 03 не начат.

### Что изменено

- `frontend/app.js`: скругление задаётся простым CSS `border-radius` в пикселях (0–50px), чтобы углы оставались круглыми на прямоугольных элементах.
- Ползунок всегда отображает `px` при первом выборе, после изменения и после повторной загрузки JSON.
- Встроенные демонстрационные карточки, кнопки и контейнеры используют px.
- При чтении старого проекта/шаблона `borderRadius: '16%'` приводится к `'16px'` (по числовому значению, без геометрических вычислений). Нестандартные и выходящие за пределы шкалы значения приводятся к 0–50px. Формат проекта остаётся `version: 3`.
- `frontend/index.html`, `README.md`, `docs/PROTOTYPE_V03.md`, `docs/ROADMAP.md`, `docs/STATE.md` отражают изменение.

### Критерии проверки

1. Открыть `frontend/index.html`, выбрать прямоугольный контейнер/кнопку.
2. Проверить скругление при 0px (нет), 15px (обычные круглые углы), 50px (сильное скругление без эллиптических деформаций).
3. Выгрузить JSON и убедиться, что `borderRadius` выбранного элемента хранится в `px`; открыть JSON повторно — подпись и внешний вид остаются корректными.
4. Загрузить JSON от версии 0.3.2 с `borderRadius` в `%`; он отображается с нормальным круглым скруглением, при последующей выгрузке записывается в `px`.
5. Проверить существующее перетаскивание, дерево, шаблоны и просмотр на предмет регрессий.
6. После успешной проверки владелец выполняет commit/push и присылает хеш.

### Что проверил ассистент

- Синтаксис `frontend/app.js` командой `node --check` — успешно.
- В Chromium через Playwright с загрузкой HTML/CSS/JS в тестовый документ проверены `0px`, `15px`, `50px` (вычисленный CSS совпадает с подписью), сохранение `50px` в JSON, загрузка старого `25%` как `25px`, отображение кнопки и вход в режим просмотра. Ошибок JavaScript не обнаружено. Прямое открытие `file://` заблокировано политикой тестовой среды; локальный запуск у владельца остаётся обязательным.
