# WEBWB

WEBWB — лёгкий визуальный редактор панелей управления для контроллеров Wiren Board.

Пользователь собирает интерфейс из контейнеров, текста, кнопок, переключателей и ползунков, настраивает внешний вид и, в будущих версиях, привязывает элементы к MQTT-топикам. Правила и автоматизация остаются на самом контроллере.

## Текущее состояние

**Шаги 01–02c подтверждены** (последний коммит: `a9ff9bc43c4748a45ca6f380111e124dd0b01bef`). **Шаг 03 подготовлен:** существующий JavaScript разделён по назначению на четыре файла без изменения функциональности редактора. MQTT, backend и CMake **ещё не реализованы**.

Реализовано в прототипе:
- Добавление элементов, дерево и вложенные контейнеры;
- Базовые CSS-свойства, Flexbox и свободное позиционирование;
- Перетаскивание на холст и внутри дерева, копирование, дублирование, шаблоны;
- Режим демонстрационного просмотра;
- Экспорт/импорт JSON, автосохранение и шаблоны в `localStorage`.

**Добавление:** перетащите элемент или шаблон на холст либо в дерево. Нажатие на плитку или шаблон не добавляет его. Для сенсорных экранов полноценное перетаскивание пока не реализовано.

## Быстрый запуск

Откройте `frontend/index.html` в современном браузере (Chrome, Edge, Firefox). HTTP-сервер, npm, сборка и интернет на этом шаге не требуются.

Для просмотра используйте кнопку **Просмотр**. Устройства не управляются: MQTT пока нет.

Подробная инструкция по интерфейсу прототипа: [docs/PROTOTYPE_V03.md](docs/PROTOTYPE_V03.md).

## Структура

```text
WEBWB/
├── .gitattributes             # уже создан в репозитории
├── .gitignore                 # уже создан в репозитории
├── README.md
├── AGENTS.md                  # соглашения по работе над кодом
├── frontend/
│   ├── index.html
│   ├── styles.css
│   ├── app.js                # история, действия и обработчики событий
│   └── js/
│       ├── model.js         # данные проекта и JSON
│       ├── view.js          # дерево и отображение элементов
│       └── properties.js    # панель свойств и изменение CSS
├── backend/
│   └── README.md              # заготовка, C++ появится на шаге 04
└── docs/
    ├── ROADMAP.md
    ├── ARCHITECTURE.md
    ├── STATE.md
    ├── PROTOTYPE_V03.md
    └── assets/editor-v0.3.png
```

JavaScript разделён по ответственности без сборщика и без ES-модулей — `index.html` по-прежнему можно открыть напрямую с диска (`file://`). Файлы подключаются по порядку с `defer`: `model.js`, `view.js`, `properties.js`, `app.js`. Для связи модулей используется небольшой объект `window.WBPanelModel` и фабрики отрисовки/свойств с передачей контекста. Это внутреннее API; API backend появится позже. После подтверждения шага 03 следующий этап — каркас C++ backend (шаг 04).
