# WEBWB

WEBWB — лёгкий визуальный редактор панелей управления для контроллеров Wiren Board.

Пользователь собирает интерфейс из контейнеров, текста, кнопок, переключателей и ползунков, настраивает внешний вид и, в будущих версиях, привязывает элементы к MQTT-топикам. Правила и автоматизация остаются на самом контроллере.

## Текущее состояние

**Шаги 01–02 и 02a подтверждены**; последний коммит: `aa372ba0fe30f8e8615c821dae3a916de2c217dc`. Подготовлено исправление 02b (frontend v0.3.3): скругление в `px` вместо `%`, чтобы углы прямоугольных элементов оставались круглыми. Ползунок и значение — 0–50 px. При открытии старых проектов значения вроде `16%` нормализуются в `16px` (не геометрическое преобразование). Backend, CMake и MQTT **ещё не реализованы**.

Реализовано в прототипе:
- Добавление элементов, дерево и вложенные контейнеры;
- Базовые CSS-свойства, Flexbox и свободное позиционирование;
- Перетаскивание на холст и внутри дерева, копирование, дублирование, шаблоны;
- Режим демонстрационного просмотра;
- Экспорт/импорт JSON, автосохранение и шаблоны в `localStorage`.

**Добавление:** перетащите элемент или шаблон на холст либо в дерево. Нажатие на плитку или шаблон не добавляет его. Для сенсорных экранов полноценное перетаскивание пока не реализовано.

## Быстрый запуск

Откройте `frontend/index.html` в современном браузере (Chrome, Edge, Firefox). HTTP-сервер, npm, сборка и интернет на этом шаге не требуются.

Для просмотра используйте кнопку **Просмотр**. Устройства не управляются: MQTT пока нет.

Подробная инструкция по интерфейсу прототипа: [docs/PROTOTYPE_V03.md](docs/PROTOTYPE_V03.md).
