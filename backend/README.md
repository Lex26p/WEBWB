# WEBWB backend — запланированный модуль

Backend будет написан на C++ и собираться в WSL через CMake. Исходники и `CMakeLists.txt` появятся на **шаге 04** по дорожной карте.

Назначение: небольшое HTTP API для хранения проектов, шаблонов, изображений и настроек приложения в файлах на Wiren Board.

Backend **не** реализует MQTT-клиент, логику автоматизации и авторизацию приложения. Внешние запросы предполагается направлять через веб-сервер контроллера на backend, слушающий loopback. Точные параметры запуска, зависимости и формат API будут согласованы перед реализацией.

Сейчас этот каталог содержит только документацию: никаких компилируемых исходников backend на шаге 01 нет.
